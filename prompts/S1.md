Using the attached scheme-dev skill, start id_q3.rkt with #lang racket/base and write only helpers: (empty-tree? t), (tree-value t), (tree-left t), (tree-right t) for trees that are () or (value left right), and a tail-recursive (my-reverse lst) with an accumulator. ## Prompt 2: the three traversals

```text
Using the scheme-dev skill and my helpers, write (inorder t), (preorder t) and (postorder t), each returning a list of values. Do not use append: pass an accumulator and build the list by visiting the tree in reverse order and consing onto the accumulator (e.g. inorder: go right subtree, cons node, then left subtree into the accumulator). Expected for t1 = (4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ()))): inorder (1 2 3 4 5 6 7), preorder (4 2 1 3 6 5 7), postorder (1 3 2 5 7 6 4). The empty tree gives ().
```

## Prompt 3: height and leaf count

```text
Using the scheme-dev skill, write (height t) and (leaf-count t). Height of () is 0; a node is 1 + max of its subtree heights. A leaf is a node whose left and right are both (); the empty tree has 0 leaves. Expected: t1 gives 3 and 4; (1 () (2 () (3 () ()))) gives 3 and 1; (a (b () ()) (c () ())) gives 2 and 2; () gives 0 and 0.
```

## Prompt 4: the print functions

```text
Using the scheme-dev skill, write (print-inorder tree), (print-all-traversals tree) and (print-height-and-leaves tree) using only display and newline. print-inorder prints the inorder list on one line; print-all-traversals prints the inorder, preorder and postorder lists on three lines; print-height-and-leaves prints (list height leaf-count) on one line. Every function ends with a newline. Nothing is printed or called at the top level of the file.
```
