# S2 prompts (plan version)

## Prompt 22: my-length, my-reverse, my-map

```text
Using the attached scheme-dev skill, start id_q4.rkt with #lang racket/base and write: (my-length lst), tail-recursive with an accumulator; (my-reverse lst), tail-recursive; (my-map f lst), which builds the result tail-recursively with an accumulator and then reverses it with my-reverse, so it does not overflow on a 10,000-element list. Only allowed built-ins. Add a recursive-reading comment above each.
```

## Prompt 23: first insert-if-short

```text
Using the scheme-dev skill and my my-length and my-map, write (insert-if-short x lst n): return lst with x consed at the front of every list (at every nesting level, including the top level and empty lists) whose ORIGINAL length (top-level elements, before insertion) is less than n. Atoms stay unchanged. Recurse into each element with my-map. Expected: x=42, lst=((1 2) (3 4 5) (6) ()), n=3 gives ((42 1 2) (3 4 5) (42 6) (42)); x=0, lst=(((1) 2) (3) ((4 5 6) ())), n=3 gives ((0 (0 1) 2) (0 3) (0 (4 5 6) (0))); x=7, lst=(), n=3 gives (7); n=0 gives ().
```

## Prompt 24: make-inserter and the final insert-if-short

```text
Using the scheme-dev skill, write the higher-order function (make-inserter x len-ok?) that returns a one-argument function: given a list, it inserts x at the front of every list at every nesting level whose original length satisfies (len-ok? length), using my-length and my-map. Then replace my old insert-if-short with (define (insert-if-short x lst n) ((make-inserter x (lambda (len) (< len n))) lst)). Give me the complete updated file section so only ONE definition of insert-if-short remains.
```

## Prompt 25: print-insert-result

```text
Using the scheme-dev skill, write (print-insert-result) with no arguments: it reads x, then lst, then n from standard input with read (in that order), and displays (insert-if-short x lst n) followed by newline. No prompt or other output. Show how to test it with: echo "42 ((1 2) (3 4 5) (6) ()) 3" | racket -e '(require (file "id_q4.rkt")) (print-insert-result)' or an equivalent that works if the file has no provide.
```

## Prompt 26: S2 tests

```text
Using the scheme-dev skill, write tests/test_q4.rkt that tests insert-if-short on the four assignment examples, n = 0 on a nested list (nothing changes), a list nested 100 deep (built with a helper), a flat list of 10,000 elements with n = 10001 and n = 5, and make-inserter with a different predicate such as (lambda (len) (= len 2)). Put the expected output as a comment next to each call, and use only allowed built-ins in the helpers.
```
